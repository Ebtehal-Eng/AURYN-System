# AURYN System (MVP)

A non-pharmacological migraine prediction and neuromodulation intervention system.

### Features
- Real-time biometric risk assessment (HRV, Sleep, Stress, Hydration, Barometric Pressure).
- Clinical AI reasoning powered by Google Gemini Pro API.
- Tailored acoustic neuromodulation protocols using Binaural Beats (Alpha, Theta, and Entrainment frequencies).
